# Agéntica Aplicada

Proyecto del **Diplomado en Agéntica Aplicada: Desarrollo de Agentes de IA en Producción**.

## Estructura

- [`backend/`](backend/): API construida con FastAPI que gestiona conversaciones y ejecuciones.
- [`frontend/`](frontend/): interfaz de usuario que consume la API del backend.
- [`ai/`](ai/): capa de agentes de IA que generará las respuestas del asistente.
